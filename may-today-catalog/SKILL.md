# MayToday 歌曲资料库

由 Diu 整理，开源在 [may-today](https://github.com/may-today) 下。

## 收录范围

目前仅收录**五月天和周杰伦**的歌曲资料与歌词，**不包含其他歌手**，也不保证完整收录这两位歌手的全部作品。涉及其他歌手时应另找数据来源，不将本资料库作为其数据来源。

## 数据来源

| 曲库 ID | 歌手 | JSON 地址 |
| --- | --- | --- |
| `mayday` | 五月天 | https://wx-static.ddiu.site/dataset/mayday.json |
| `jayzhou` | 周杰伦 | https://wx-static.ddiu.site/dataset/jayzhou.json |

两个文件均为 UTF-8 JSON，顶层是歌曲对象数组。按任务读取对应曲库；曲目数量及内容可能更新，不假定收录了歌手的全部作品。歌手身份由上述曲库映射确定，当前文件没有逐首 `artist` 字段。数据不包含音频或音频地址。

## 字段定义

### 歌曲对象

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `title` | string | 歌曲名称 |
| `slug` | string | 曲库内歌曲标识；跨曲库使用时建议与曲库 ID 组合 |
| `meta` | object | 歌曲资料，见下表 |
| `detail` | array | 按行保存的歌词对象，见歌词行定义 |

### 歌曲资料 `meta`

| 字段 | 类型 | 含义与可用性 |
| --- | --- | --- |
| `year` | number | 曲库记录的发行年份；没有月、日，不能据此生成完整发行日期 |
| `album` | string，可缺失 | 专辑名称 |
| `lyricist` | string | 作词者，保留来源中的署名文本 |
| `composer` | string | 作曲者，保留来源中的署名文本 |
| `banlam` | boolean | 是否标记为闽南语歌曲 |
| `length` | number，可缺失 | 歌曲时长，单位秒；当前五月天曲库有，周杰伦曲库没有 |

这里只说明供使用方使用的字段，源文件中未列出的字段忽略即可。不保证每首歌的资料完整或未来字段不变。缺失信息保留为空或标注未知；不能把最后一行歌词的时间当作准确歌曲时长。需要精确发行日期或缺失资料时另行核实，并区分外部补充信息与曲库原始字段。

### 歌词行 `detail[]`

| 字段 | 类型 | 含义与可用性 |
| --- | --- | --- |
| `time` | number 或 null | 从歌曲开始计的秒数，可带小数；实际数据有 `-1` 和 `null`，应视为无有效时间信息，不能直接作为同步时间 |
| `text` | string | 该行文字，允许空字符串 |
| `isHighlight` | boolean | 该行是否为副歌：`true` 表示副歌，`false` 表示非副歌 |
| `toneText` | string，可缺失 | 辅助注音文本；当前仅五月天部分行有 |
| `toneText2` | string，可缺失 | 第二组辅助注音文本；当前仅五月天部分行有 |

注音字段的具体标音体系未在数据中声明，不自行赋予拼音、音标或翻译等确定含义。保留源文件的行顺序、时间精度和重复歌词；展示时应兼容空行、无效时间和同一时间多行。

## 本地使用与缓存建议

- 开发或分析时先检查已有本地缓存，首次需要时下载对应文件并复用；不要为每首歌或每次渲染重复下载整个曲库。
- 缓存位置沿用目标项目约定，例如 `.cache/song-catalog/`，可记录来源 URL 和下载时间。需要最新数据时显式刷新；刷新失败时可使用已有缓存并说明状态，没有可用数据时明确告知。
- 应用运行时可按需要将所需数据随应用打包，或使用应用自身的持久化缓存。由目标项目决定加载方式，无需特定查询工具或运行环境。
- 下载后先检查 JSON 顶层及所需字段；查询和转换使用目标环境现有工具完成。只读取或输出任务需要的歌曲及字段，避免把整个歌词库塞入模型上下文。

## 使用数据

资料查询可以按歌曲、专辑、年份或词曲作者组织结果；同名或多个候选时利用曲库、专辑等信息区分。歌词展示、词云、文本统计及其他创意应用可按目标自由设计，不限于提词器。

制作词云或统计词频时，以 `detail[].text` 为文本来源，按需求决定分词、停用词和重复段落是否计入；说明会影响结果的统计口径。清洗、去重或改写产生的是派生数据，保留原始数据以便复用。未知字段不猜测语义，缺失歌词与元数据不编造。
